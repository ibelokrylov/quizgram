# Как работает оплата в Quizgram

## Архитектура оплаты

### Бэкенд (`pkg/api/src/modules/payment/`)

**API endpoints:**

- `POST /v1/payment/:planId` — обновление плана пользователя
- `GET /v1/payment/up-limits` — получение дополнительных лимитов для Pro+

**Сервис `PaymentService`:**

- Бизнес-логика обновления планов
- Создание/обновление записей в `user_payment`
- Учёт уже собранных заявок при переходе на платный план
- Отложенные планы при понижении тарифа

### Фронтенд

- `/app/payment` — страница выбора плана (PaymentPage)
- `PaymentMethodDrawer` — диалог подтверждения/способа оплаты
- `/app/payment/success` — страница успешной оплаты
- `/app/payment/failure` — страница неудачной оплаты
- `/app/payment/waiting` — страница ожидания оплаты (polling статус)

### База данных

- `payment` — записи платежей (статус, метод, провайдер, invoiceUrl)
- `user_payment` — активные и отложенные планы пользователя
- `plan` — тарифы: FREE, BASE (Pro), PRO_PLUS
- `up_limit` — дополнительные лимиты заявок для Pro+

## Тарифы

- **FREE**: 0 ₽, 10 заявок/мес
- **BASE (Pro)**: 899 ₽, 100 заявок/мес
- **PRO+**: 1490 ₽, 200 заявок/мес + возможность добавлять лимиты (+1000/2000/3000/5000 заявок)
