# Визуальная схема GitHub Actions Workflows

## Полный процесс CI/CD

```
┌─────────────────────────────────────────────────────────────────────┐
│                         РАЗРАБОТЧИК                                  │
└─────────────────────────────────────────────────────────────────────┘
                                  │
                                  │ Изменяет код
                                  │ git add, git commit
                                  ↓
┌─────────────────────────────────────────────────────────────────────┐
│                         git push main                                │
└─────────────────────────────────────────────────────────────────────┘
                                  │
                                  │ Автоматически
                                  ↓
╔═════════════════════════════════════════════════════════════════════╗
║                    STAGE 1: BUILD (автоматически)                   ║
║                         Workflow: build.yml                         ║
╠═════════════════════════════════════════════════════════════════════╣
║                                                                     ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 1. Checkout код                                             │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 2. Установка Bun + зависимости                              │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 3. Проверка TypeScript (pkg/api)                            │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║  ┌──────────────────┐    ┌──────────────────┐                     ║
║  │ 4a. Сборка       │    │ 4b. Сборка       │                     ║
║  │     pkg/app      │    │     pkg/tg-quiz  │                     ║
║  │  (React 19)      │    │  (Telegram)      │                     ║
║  └──────────────────┘    └──────────────────┘                     ║
║            │                       │                                ║
║            └───────────┬───────────┘                                ║
║                        ↓                                            ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 5. Проверка dist/ директорий                                │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 6. Загрузка артефактов (хранятся 7 дней)                    │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║                         ✅ УСПЕХ                                    ║
╚═════════════════════════════════════════════════════════════════════╝
                                  │
                                  │ Если сборка успешна
                                  │
                    ┌─────────────┴─────────────┐
                    │                           │
                    │  Разработчик проверяет    │
                    │  результаты сборки        │
                    │                           │
                    └─────────────┬─────────────┘
                                  │
                                  │ Вручную запускает деплой
                                  ↓
╔═════════════════════════════════════════════════════════════════════╗
║                   STAGE 2: DEPLOY (вручную)                         ║
║                        Workflow: deploy.yml                         ║
╠═════════════════════════════════════════════════════════════════════╣
║                                                                     ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 1. Проверка секретов                                        │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 2. SSH подключение к серверу                                │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 3. git pull (если не skip_git_pull)                         │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 4. Создание .env файлов (если не skip_env_update)           │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 5. Docker Hub авторизация                                   │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 6. docker compose up -d --build app api tg-quiz             │  ║

║  │    ⚠️  PostgreSQL НЕ перезапускается!                       │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐            ║
║  │   app        │  │   api        │  │   tg-quiz    │            ║
║  │ (frontend)   │  │ (backend)    │  │ (Telegram)   │            ║
║  │ Port: 5173   │  │ Port: 5001   │  │ Port: 5174   │            ║
║  └──────────────┘  └──────────────┘  └──────────────┘            ║
║                              ↓                                      ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 7. Проверка статуса контейнеров                             │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║  ┌─────────────────────────────────────────────────────────────┐  ║
║  │ 8. Показ последних логов                                    │  ║
║  └─────────────────────────────────────────────────────────────┘  ║
║                              ↓                                      ║
║                         ✅ УСПЕХ                                    ║
╚═════════════════════════════════════════════════════════════════════╝
                                  │
                                  ↓
┌─────────────────────────────────────────────────────────────────────┐
│                    PRODUCTION СЕРВЕР                                 │
│                                                                      │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐             │
│  │   app        │  │   api        │  │   tg-quiz    │             │
│  │ (обновлён)   │  │ (обновлён)   │  │ (обновлён)   │             │
│  └──────────────┘  └──────────────┘  └──────────────┘             │
│                                                                      │
│  ┌──────────────────────────────────────────────────────┐          │
│  │   postgres (НЕ ТРОНУТ, продолжает работать)          │          │
│  └──────────────────────────────────────────────────────┘          │
└─────────────────────────────────────────────────────────────────────┘
```

## Сравнение: Старый vs Новый процесс

### Старый процесс (до 2025-12-16)

```
git push main
     ↓
┌────────────────────────────┐
│  Deploy Workflow           │
│  (автоматически)           │
│                            │
│  1. Сборка на runner       │
│  2. Обновление кода        │
│  3. Перезапуск ВСЕХ        │
│     контейнеров            │
│     (включая PostgreSQL!)  │
└────────────────────────────┘
     ↓
⚠️ Риск: PostgreSQL может
   перезапуститься
```

### Новый процесс (после 2025-12-16)

```
git push main
     ↓
┌────────────────────────────┐
│  Build Workflow            │
│  (автоматически)           │
│                            │
│  1. Проверка сборки        │
│  2. Артефакты              │
└────────────────────────────┘
     ↓
     Проверка результатов
     ↓
┌────────────────────────────┐
│  Deploy Workflow           │
│  (вручную!)                │
│                            │
│  1. Обновление кода        │
│  2. Перезапуск ТОЛЬКО      │
│     app, api, tg-quiz      │
└────────────────────────────┘
     ↓
✅ Безопасно: PostgreSQL
   не трогаем
```

## Безопасность PostgreSQL

```
┌─────────────────────────────────────────────────────────────┐
│                    PostgreSQL Контейнер                      │
│                                                              │
│  ┌────────────────────────────────────────────────────┐     │
│  │  Данные: /var/lib/postgresql/data                  │     │
│  │  Volume: postgres-data                             │     │
│  └────────────────────────────────────────────────────┘     │
│                                                              │
│  🛡️ ЗАЩИТА:                                                 │
│                                                              │
│  ✅ НЕ перезапускается в deploy.yml                         │
│  ✅ Данные сохраняются в Docker volume                      │
│  ✅ Backup рекомендуется делать перед перезапуском          │
│                                                              │
└─────────────────────────────────────────────────────────────┘

Команды деплоя:

❌ НИКОГДА:
   docker compose up -d --build  (все контейнеры)
   docker compose restart        (все контейнеры)

✅ ВСЕГДА:
   docker compose up -d --build app api tg-quiz
   (только приложения, БД не трогаем)
```

╔═════╗  Важный этап (Stage)

   ↓

   │

✅       Успех
